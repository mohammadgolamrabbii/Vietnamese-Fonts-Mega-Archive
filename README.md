## 🌟 Overview & Typographical Architecture

Vietnamese (*Tiếng Việt*) features one of the world's most intricate Latin-based writing systems, employing **6 distinct tones** (ngang, huyền, sắc, hỏi, ngã, nặng) and stacked double-diacritics (`ấ, ầ, ẩ, ẫ, ậ; ắ, ằ, ẳ, ẵ, ặ; ế, ề, ể, ễ, ệ; ố, ồ, ổ, ỗ, ộ; ớ, ờ, ở, ỡ, ợ; ứ, ừ, ử, ữ, ự`).

Standard generic Latin fonts frequently suffer from clipped diacritics, unanchored tone marks, and glyph fallback. This archive brings together **3,000+ verified production TrueType (.ttf) and OpenType (.otf) typefaces** with complete OpenType Mark-to-Base (`mark`) and Mark-to-Mark (`mkmk`) anchor positioning tables, fully compliant with modern operating systems and design software (Adobe Photoshop, Illustrator, InDesign, Figma, Canva, MS Office).

## ⚡ 1-Click Terminal Fast Installers (Zero Rate-Limits)

### 🐧 Linux / macOS Terminal:
```bash
curl -fsSL https://mohammadgolamrabbii.github.io/typography/install.sh | bash -s -- vietnamese
```
*(Installs to `~/.local/share/fonts/opentypography/vietnamese` and refreshes `fc-cache`)*

### 🪟 Windows PowerShell:
```powershell
& ([scriptblock]::Create((irm https://mohammadgolamrabbii.github.io/typography/install.ps1))) -Language Vietnamese
```
*(Registers directly into Windows Font Registry; immediately accessible in Photoshop, Illustrator, Word, Figma)*
